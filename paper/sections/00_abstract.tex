\noindent\textbf{Abstract.}
Can an observer recover a source state from its measurements, and can it determine from the possible outputs whether recovery is feasible? For a deterministic observation map, the first question depends on which states share an output. The second depends on which latent models the observer admits. We prove that adjoining an unobserved Boolean coordinate to any nonempty latent model preserves every possible output of every fixed observation processing rule. The two labels prevent exact recovery of the extended state. For each nonempty reachable set, a model class that includes the inclusion map and its Boolean extension therefore contains models with opposite decoder statuses. In a six-output example, increasing the number of hidden labels from one to eight raises the number of indistinguishable state pairs from zero to 168 while preserving all six outputs. A refinement can recover a target quantity precisely when its measurements separate every pair on which that quantity differs. These results specify what a report can establish about an observer's internal state under a declared interface.

\medskip
\noindent\textbf{Keywords:} observer interface, reachable observations, latent reconstruction, identifiability, quotient, interface refinement.
