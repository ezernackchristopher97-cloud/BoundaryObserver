\noindent\textbf{Abstract.}
Two internal states can produce the same report. A deterministic measurement identifies a target quantity exactly when the quantity has the same value for all states that produce each report. The set of possible reports can leave the existence of an exact state decoder undecided when the admissible models allow hidden labels. For every nonempty set of reports, one model takes the reports themselves as its states. A second model attaches a hidden binary label to each state. Both models produce the same reports under every fixed rule for processing the output. Only the first model permits exact state reconstruction. In a model with six reports, increasing the number of hidden labels per report from one to eight raises the number of indistinguishable state pairs from zero to 168. A second measurement identifies a target if it separates every pair of states with the same report and different target values. This condition specifies what an additional measurement would need to establish about an observer's internal state.

\medskip
\noindent\textbf{Keywords:} observer interface, reachable observations, latent reconstruction, identifiability, quotient, interface refinement.
