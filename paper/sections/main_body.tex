\section{Introduction}
\label{sec:mainintro}
A person can give the same report on two occasions. A scientist may know which response the person gave while several internal states remain consistent with that response. The same problem arises for an observer that uses its own reports to infer its internal state. In either case, the question is which differences between states survive the measurement.

A known observation map permits a direct test of whether a quantity can be recovered. When only the set of possible outputs is known, recovery also depends on which source models are admissible. Statistical identifiability compares probability laws, and dynamical observability uses records over time \parencite{Rothenberg1971,HermannKrener1977}. The evidence considered here consists of the possible outputs of a deterministic map. Model restrictions play a comparable role in the recovery of latent representations from data \parencite{Locatello2019}.

For any nonempty set of possible outputs, two models illustrate how recovery depends on these restrictions. In one model the output identifies its source. In the other, two hidden labels for each source give identical outputs. Finite examples quantify how many states a report can conceal. A condition on a second measurement determines when the combined readings identify a specified target.

\section{Observation and reconstruction}
\label{sec:mainframework}
An interface is a map \(\pi:X\to O\) from a source state space to an observation space. Two states are observationally equivalent when their outputs agree:
\begin{equation}
x\sim_\pi y\ \Longleftrightarrow\ \pi(x)=\pi(y),
\qquad Q_\pi=X/{\sim_\pi}.
\label{eq:stateequivalence}
\end{equation}
Each class is a fiber of \(\pi\). The quotient \(Q_\pi\) is in bijection with the reachable range \(\pi[X]\). The observation determines a quantity \(f:X\to V\) on this range exactly when \(f\) is constant on each fiber. In that case \(f\) factors uniquely through the quotient. Constructing an algorithm or bounding its error requires further assumptions.

A globally exact decoder is a total map \(d:O\to X\) such that
\begin{equation}
d\circ\pi=\id_X.
\label{eq:decoder}
\end{equation}
Applying \(d\) to \(\pi(x)=\pi(y)\) gives \(x=y\), so exact decoding requires injectivity. For nonempty \(X\), injectivity also suffices. Invert \(\pi\) on its range and choose one fixed state for unreachable observations. When \(X=\varnothing\), a decoder defined on all of \(O\) exists exactly when \(O=\varnothing\).

A model \(\Model=(X_\Model,\pi_\Model)\) has reachable set \(\Obs(\Model)=\pi_\Model[X_\Model]\). Models with the same observation codomain are compared by
\begin{equation}
\Model\approx\Model'\ \Longleftrightarrow\
\Obs(\Model)=\Obs(\Model').
\label{eq:modelequivalence}
\end{equation}
\emph{Empirical equivalence} compares sets of possible observations. Their probabilities can differ. A fixed function \(e:O\to R\) processes an observation into an experimental outcome. Its possible outcomes are
\begin{equation}
\Out_e(\Model)=e[\Obs(\Model)],\qquad
\Model\approx\Model'\ \Longrightarrow\
\Out_e(\Model)=\Out_e(\Model').
\label{eq:outcomes}
\end{equation}
The function \(e\) acts only on the existing observation. An intervention or a sequence of measurements requires a model of how the system evolves.

Interfaces on the same source space can retain different distinctions. A fine interface \(\pi_F:X\to O_F\) refines \(\pi_C:X\to O_C\) when a coarsening map \(c\) satisfies
\begin{equation}
\pi_C=c\circ\pi_F.
\label{eq:refinement}
\end{equation}
This relation is reflexive and transitive. It induces a surjection \([x]_F\mapsto[x]_C\) between observable quotients. If a pair is separated by \(F\) and merged by \(C\), that quotient map is noninjective and reverse refinement is impossible. The proofs are in \Cref{sec:interfaces,sec:observablequotient,sec:refinement}.

\section{Hidden states with identical outputs}
\label{sec:mainresult}
A hidden binary label can prevent state reconstruction while preserving every output. For a model with \(X_\Model\neq\varnothing\), define
\begin{equation}
X_{\Extended}=X_\Model\times\{0,1\},\qquad
\pi_{\Extended}(x,b)=\pi_\Model(x),\qquad p(x,b)=x.
\label{eq:extension}
\end{equation}
The map \(p\) is surjective and preserves observations. Distinct Boolean labels over the same base state produce a collision.

\begin{theorem}[Hidden extension and reconstruction]
For every model with a nonempty latent space, the extension in \eqref{eq:extension} has the same reachable set and the same possible outcomes under every fixed observation processing map \(e\). It has no globally exact decoder. If the base has an exact decoder, the two models have different decoder statuses.
\label{thm:mainhidden}
\end{theorem}

Every base output \(\pi_\Model(x)\) occurs at \((x,0)\). Every extended output has this form. The two states \((x,0)\) and \((x,1)\) thus have the same observation. Equation~\eqref{eq:decoder} rules out an exact decoder for the extension (\Cref{sec:hidden,sec:synthesis}).

This ambiguity holds for any nonempty set of possible observations \(S\subseteq O\), provided the model class admits both constructions. Take the latent space to be \(S\) itself and the observation map to be the inclusion \(S\hookrightarrow O\). An exact decoder returns the observed value on \(S\) and a fixed element of \(S\) elsewhere. The Boolean extension also reaches exactly \(S\), but it has no exact decoder. For \(S=\varnothing\) every compatible latent space is empty, and a total decoder exists exactly when \(O=\varnothing\). \Cref{sec:empiricalquotient} gives the proof.

Even all Boolean tests on observations leave this ambiguity. Such a test succeeds if some reachable output satisfies it. Tests for equality to individual outputs determine membership in the reachable set. Agreement on every test is thus equivalent to equality of reachable sets. A model property descends to the empirical quotient exactly when it is constant on each of these classes (\Cref{sec:predicates,sec:empiricalquotient}).

\section{Methods}
\label{sec:mainmethods}
The finite calculations enumerate source states and group them by their outputs. The supplement gives the code, data tables, and Lean declarations for the corresponding mathematical results.

The finite base has \(X=O=\{0,1,2,3,4,5\}\) and \(\pi(x)=x\). A comparison model observes \(x\bmod3\). The implementation stores its three output labels. For comparison across models we include those labels in the common observation space \(O\). Hidden extensions use \(m\in\{1,2,3,5,8\}\) labels for each base state, with \(\pi_m(x,h)=x\). For each reachable output, the program enumerates its fiber and calculates
\begin{equation}
C(\Model)=\sum_{o\in\Obs(\Model)}\binom{|\pi_\Model^{-1}(o)|}{2},
\qquad C(\Model_m)=3m(m-1).
\label{eq:collisions}
\end{equation}
Each pair contributes once when both states produce the same output.

Four rules process the output of each of seven representations of the six-output base. The rules return the original label, a threshold indicator, one of three categories, or the index of a bin of width two. Three predicates test evenness, values of at least three, and membership in \(\{0,5\}\). A separate example compares four interfaces on eight states. The interfaces are identity, paired buckets, binary regions, and relabeled identity.

The program regenerates twelve CSV tables for comparison with the archived outputs. The supplement gives the commands to reproduce the calculations.

The four rules produce respectively six, two, three, and three possible outcomes. Each rule gives the same outcome set for all seven representations. Each of the three predicates also has the same truth table on the six reachable labels in all seven cases. These counts include the base itself and two ways of representing a two-label extension.

The identity, paired bucket, and binary region interfaces retain eight, four, and two classes, respectively. Grouping the identity outputs into pairs merges four previously distinct pairs of states. Grouping the paired outputs into regions merges eight more. Passing directly from identity to regions merges twelve pairs. Each map between these quotients is surjective and noninjective. Relabeling preserves all eight classes (\Cref{sec:results}).

The 26 computational tests pass, and the twelve regenerated tables match the archived files byte for byte. The counts cover all states in the specified finite domains.

\section{Discussion}
\label{sec:maindiscussion}
A second measurement can distinguish states with the same report. Suppose the report is \(\pi(x)\) and the target quantity is \(f(x)\). A second reading \(r(x)\) identifies the target from the joint observations exactly when
\begin{equation}
\pi(x)=\pi(y)\ \text{and}\ f(x)\ne f(y)
\quad\Longrightarrow\quad r(x)\ne r(y)
\qquad (x,y\in X).
\label{eq:jointtarget}
\end{equation}
Each fiber of \((\pi,r)\) is the intersection of a report fiber with a fiber of the second measurement. Equation~\eqref{eq:jointtarget} makes \(f\) constant on each intersection. Other aspects of the source state can vary within that intersection.

Two models can reach the same outputs with different probabilities. Bernoulli laws with parameters \(1/10\) and \(9/10\) both permit zero and one, but assign different probabilities to one. Comparing these models statistically requires the induced probability laws \parencite{Rothenberg1971}.

Observations taken at different times can distinguish states that share one instantaneous output. For the known system
\begin{equation}
\dot x_1=x_2,\qquad\dot x_2=0,\qquad y=x_1,
\end{equation}
one output leaves \(x_2\) undetermined, while \(y(0)\) and \(y(T)\), for \(T\neq0\), determine both initial coordinates. Measurement error in the reconstructed second coordinate is amplified as \(|T|\) becomes small. The derivation and error bound are in \Cref{app:scopechecks}. This distinction is consistent with dynamical observability theory \parencite{HermannKrener1977}.

Neural applications require the same separation between source state, measurement, and reconstruction. Gardner and colleagues recovered toroidal population geometry from simultaneous grid-cell recordings \parencite{Gardner2022}. A spatial tuning map and a time series of joint activity retain different information. To infer attraction from reconstructed geometry one also needs a model of evolution and evidence that trajectories approach the proposed invariant set.

A study of conscious experience could combine a report with a physiological measurement. The additional reading would have to distinguish every pair of states with the same report and different target values. Applying this criterion requires a definition of the target and independent evidence for the measurement model. Feedback through self-observation and continuity across scales raise further questions (\Cref{sec:limitations,app:motivation}).

\section{Conclusion}
\label{sec:mainconclusion}
A measurement identifies exactly those target quantities that agree throughout each observation fiber. Knowledge of all possible reports can still leave open whether the state that produced them is exactly reconstructible. The inclusion model and its Boolean extension exhibit both possibilities for the same nonempty set of reports.

For an embedded observer, an explanation of internal state must specify what the report measures. A further reading or a justified physical restriction must resolve any differences in the target that the report leaves open.
