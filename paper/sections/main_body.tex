\section{Introduction}
\label{sec:mainintro}
A person can give the same report on two occasions. Which aspects of the person's internal state can a scientist infer from that report? A report may identify a task response even when several source states could have produced it. The corresponding mathematical question is which distinctions the recording procedure preserves. For an embedded observer, the same question arises when its own report serves as evidence about its internal state.

Two inference problems follow. Given a particular observation map, one can ask whether it determines a target quantity. Given only the set of possible observations, one can ask whether every compatible model permits reconstruction of its entire state. Statistical identifiability compares probability laws, and dynamical observability uses records across time \parencite{Rothenberg1971,HermannKrener1977}. Here the evidence consists of the possible outputs of a deterministic map. The dependence on the allowed model class has a counterpart in work on recovering latent representations from data \parencite{Locatello2019}.

We construct two models that reach exactly the same observations. One admits exact reconstruction. The other assigns two hidden labels to every state and produces the same output for either label. Sections~\ref{sec:mainframework} and~\ref{sec:mainresult} give the reconstruction criterion and the construction. Sections~\ref{sec:mainmethods} and~\ref{sec:mainfindings} enumerate finite examples. The discussion considers what a second measurement could distinguish. The appendices give the proofs and develop the broader questions about self-observation.

\section{Observation model and principal equations}
\label{sec:mainframework}
An interface is a map \(\pi:X\to O\) from a source state space to an observation space. Two states are observationally equivalent when their outputs agree:
\begin{equation}
x\sim_\pi y\ \Longleftrightarrow\ \pi(x)=\pi(y),
\qquad Q_\pi=X/{\sim_\pi}.
\label{eq:stateequivalence}
\end{equation}
Each class is a fiber of \(\pi\). The quotient \(Q_\pi\) is bijective with the reachable range \(\pi[X]\). A quantity \(f:X\to V\) is determined on that range precisely when it is constant on every fiber, equivalently when it factors uniquely through the quotient. An algorithm or an error bound requires additional structure.

A globally exact decoder is a total map \(d:O\to X\) such that
\begin{equation}
d\circ\pi=\id_X.
\label{eq:decoder}
\end{equation}
Applying \(d\) to \(\pi(x)=\pi(y)\) gives \(x=y\), so exact decoding requires injectivity. For nonempty \(X\), injectivity suffices. Invert \(\pi\) on its range and choose one fixed state for unreachable observations. When \(X=\varnothing\), a total decoder exists exactly when \(O=\varnothing\). The definitions distinguish a decoder on all of \(O\) from one defined only on reachable observations.

A model \(\Model=(X_\Model,\pi_\Model)\) has reachable set \(\Obs(\Model)=\pi_\Model[X_\Model]\). Models with the same observation codomain are compared by
\begin{equation}
\Model\approx\Model'\ \Longleftrightarrow\
\Obs(\Model)=\Obs(\Model').
\label{eq:modelequivalence}
\end{equation}
Throughout this paper, \emph{empirical equivalence} means this equality of reachable sets. No probability law is part of the definition. An admissible experiment is a fixed function \(e:O\to R\) that processes an observation. Its possible outcomes are
\begin{equation}
\Out_e(\Model)=e[\Obs(\Model)],\qquad
\Model\approx\Model'\ \Longrightarrow\
\Out_e(\Model)=\Out_e(\Model').
\label{eq:outcomes}
\end{equation}
Such an experiment neither changes the source dynamics nor acquires another measurement. Interventions and temporal records require an enlarged model.

Interfaces on the same source space can retain different distinctions. A fine interface \(\pi_F:X\to O_F\) refines \(\pi_C:X\to O_C\) when a coarsening map \(c\) satisfies
\begin{equation}
\pi_C=c\circ\pi_F.
\label{eq:refinement}
\end{equation}
This relation is reflexive and transitive. It induces a surjection \([x]_F\mapsto[x]_C\) between observable quotients. If a pair is separated by \(F\) and merged by \(C\), that quotient map is noninjective and reverse refinement is impossible. The proofs are in \Cref{sec:interfaces,sec:observablequotient,sec:refinement}.

\section{Main result: equivalent outputs and nonunique latent models}
\label{sec:mainresult}
The hidden extension makes the reconstruction limit explicit. For a model with \(X_\Model\neq\varnothing\), define
\begin{equation}
X_{\Extended}=X_\Model\times\{0,1\},\qquad
\pi_{\Extended}(x,b)=\pi_\Model(x),\qquad p(x,b)=x.
\label{eq:extension}
\end{equation}
The map \(p\) is surjective and preserves observations. Distinct Boolean labels over the same base state produce a collision.

\begin{theorem}[Hidden extension and reconstruction]
For every model with a nonempty latent space, the extension in \eqref{eq:extension} has the same reachable set and the same possible outcomes under every fixed observation processing map \(e\). It has no globally exact decoder. If the base has an exact decoder, the two models have different decoder statuses.
\label{thm:mainhidden}
\end{theorem}

The proof follows from two identities. Each base output is produced by \((x,0)\), and every extended output is a base output. Meanwhile, \((x,0)\) and \((x,1)\) are distinct states with the same observation. Equation~\eqref{eq:decoder} excludes a decoder. The complete construction and supporting results appear in \Cref{sec:hidden,sec:synthesis}.

This ambiguity holds for any nonempty set of possible observations \(S\subseteq O\), provided the model class admits both constructions. Take the latent space to be \(S\) itself and the observation map to be the inclusion \(S\hookrightarrow O\). An exact decoder returns the observed value on \(S\) and a fixed element of \(S\) elsewhere. The Boolean extension also reaches exactly \(S\), but it has no exact decoder. For \(S=\varnothing\) every compatible latent space is empty, and a total decoder exists exactly when \(O=\varnothing\). \Cref{sec:empiricalquotient} gives the proof.

The same limitation holds for a complete family of Boolean predicates on observations. A predicate records whether it succeeds at any reachable output. Agreement for all predicates is equivalent to reachable-set equality, because predicates testing equality to individual observations determine membership. Model properties descend to the empirical quotient exactly when they are constant on its classes. These statements are proved in \Cref{sec:predicates,sec:empiricalquotient}.

\section{Methods}
\label{sec:mainmethods}
The proofs characterize all maps satisfying the stated hypotheses. The finite calculations enumerate the states of specified examples. The supplement identifies the reference implementation, the corresponding Lean declarations, and the archived tables.

The finite base has \(X=O=\{0,1,2,3,4,5\}\) and \(\pi(x)=x\). A comparison model observes \(x\bmod3\). The implementation stores its three output labels. For comparison across models we include those labels in the common observation space \(O\). Hidden extensions use \(m\in\{1,2,3,5,8\}\) labels for each base state, with \(\pi_m(x,h)=x\). For each reachable output, the program enumerates its fiber and calculates
\begin{equation}
C(\Model)=\sum_{o\in\Obs(\Model)}\binom{|\pi_\Model^{-1}(o)|}{2},
\qquad C(\Model_m)=3m(m-1).
\label{eq:collisions}
\end{equation}
Each pair contributes once when both states produce the same output.

For each of the seven representations of the six-output base we evaluate four processing rules. They return the original label, a threshold indicator, one of three categories, or the index of a bin of width two. Three predicates test evenness, values at least three, and membership in \(\{0,5\}\). A separate eight state example compares identity, paired buckets, binary regions, and a relabeled identity. Every claimed finite relation is evaluated over its full declared domain.

We regenerate the twelve CSV tables and compare their bytes with the archived outputs. The supplement gives the test commands and points to the Lean build for the source used here. The examples in \Cref{app:scopechecks} are proved directly in the appendix.

\section{Findings}
\label{sec:mainfindings}
The finite calculations reproduce the predicted separation between latent multiplicity and reachable outputs. The injective base has six singleton fibers and a decoder. Its Boolean extension has twelve states, six two-state fibers, and no decoder. The modulo three comparison has three reachable outputs, three collisions, and no decoder.

The four rules produce respectively six, two, three, and three possible outcomes. Each rule gives the same outcome set for all seven representations. Each of the three predicates also has the same truth table on the six reachable labels in all seven cases. These counts include the base itself and two ways of representing a two-label extension.

Refinement retains eight, four, and two observable classes for identity, paired buckets, and binary regions. Identity to paired, paired to region, and identity to region respectively collapse four, eight, and twelve previously distinguished pairs. Each induced quotient map is surjective and noninjective. Relabeling preserves all eight classes and gives a bijection. Complete tables and figures appear in \Cref{sec:results} and the supplement.

All 26 manuscript tests pass, and all twelve regenerated tables match the archived bytes. The counts exhaust the declared finite domains. The extension theorem supplies the result for arbitrary nonempty latent spaces.

\section{Discussion}
\label{sec:maindiscussion}
A proposed second measurement has a precise job. Suppose a report \(\pi(x)\) is available and the target is a quantity \(f(x)\). A second reading \(r(x)\) makes the target identifiable on the reachable joint observations exactly when
\begin{equation}
\pi(x)=\pi(y)\ \text{and}\ f(x)\ne f(y)
\quad\Longrightarrow\quad r(x)\ne r(y)
\qquad (x,y\in X).
\label{eq:jointtarget}
\end{equation}
Indeed, each fiber of \((\pi,r)\) is the intersection of a report fiber and a second-reading fiber. Equation~\eqref{eq:jointtarget} says that \(f\) is constant on each such intersection. This gives a test for a proposed measurement even when reconstructing the entire state would require more information.

Equality of reachable sets is weaker than statistical equivalence. Bernoulli laws with parameters \(1/10\) and \(9/10\) both permit the outputs zero and one, but assign different probabilities to them. The present definition omits that distinction. A statistical extension must compare induced probability laws or likelihoods rather than only possible outputs \parencite{Rothenberg1971}.

An instantaneous collision also need not prevent reconstruction from time dependent observations. For the known system
\begin{equation}
\dot x_1=x_2,\qquad\dot x_2=0,\qquad y=x_1,
\end{equation}
one output leaves \(x_2\) undetermined, while \(y(0)\) and \(y(T)\), for \(T\neq0\), determine both initial coordinates. Measurement error in the reconstructed second coordinate is amplified as \(|T|\) becomes small. The derivation and error bound are in \Cref{app:scopechecks}. This distinction is consistent with dynamical observability theory \parencite{HermannKrener1977}.

Neural applications require the same separation between source state, measurement, and reconstruction. Gardner and colleagues recovered toroidal population geometry from simultaneous grid-cell recordings \parencite{Gardner2022}. A spatial tuning map and a time series of joint activity retain different information. To infer attraction from reconstructed geometry one also needs a model of evolution and evidence that trajectories approach the proposed invariant set.

For a study of conscious experience, a report specifies one observation interface. A proposed physiological reading could refine it if two states with the same report but different target values give different readings. Establishing this requires a justified target and an independently testable measurement model. The hidden label in the theorem illustrates the ambiguity before those choices are made. The conjectures about embedded self-modeling and continuity across scales appear in \Cref{sec:limitations,app:motivation}.

\section{Conclusion}
\label{sec:mainconclusion}
A measurement identifies exactly those target quantities that agree throughout each observation fiber. Knowledge of all possible reports can still leave open whether the state that produced them is exactly reconstructible. The inclusion model and its Boolean extension exhibit both possibilities for the same nonempty set of reports.

For an embedded observer this puts a concrete requirement on a proposed explanation of internal state. It must specify the target, the reports the system can produce, and a measurement or physical assumption that distinguishes states with the same report and different target values.
